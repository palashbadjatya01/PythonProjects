What is this exam?

The Claude Certified Architect — Foundations exam validates that you understand how to design, build, and reason about applications powered by Claude. It's a knowledge exam focused on the architectural decisions and best practices an engineer makes when working with the Claude platform — from prompting and the Messages API to tool use, the Model Context Protocol (MCP), agentic systems, Claude Code, safety, and cost optimization.

Who should take it?

  • Software engineers & developers building AI features or products on the Anthropic API.
  • Solution architects & tech leads who design LLM-powered systems and need to make sound trade-offs (cost, latency, reliability, safety).
  • AI/ML practitioners moving from experimentation to production deployments with Claude.
  • Developer advocates, consultants, and founders who want a recognized credential demonstrating Claude expertise.
  • Anyone who has been building with Claude and wants to formalize and validate their foundational knowledge.

No formal prerequisites — but hands-on experience building at least one project with the Claude API or Claude Code makes the material click much faster.

What will be asked? — Core domains

The exam draws from these areas. Each maps directly to a topic in the practice test, so your results screen tells you which of these to focus on.

Prompting & Context Engineering

System prompts, personas, few-shot examples, chain-of-thought, prefilling, negative constraints, context-window management, compaction.

Messages API & Streaming

Roles, content blocks, stop_reason, tool-use loop, streaming events, parameters (temperature, max_tokens), versioning, error handling.

Tool Use & MCP

Tool definitions & schemas, tool_choice, parallel tool calls, the Model Context Protocol — Tools, Resources, Prompts, Roots, Sampling, transports.

Agents & Multi-Agent Systems

Agentic loops, orchestrator–worker patterns, delegation, shared state, parallel vs. sequential execution, checkpointing, error recovery.

Claude Code & Skills

CLAUDE.md, settings & permissions, slash commands, hooks, .claudeignore, MCP integration, agentic development workflows.

Safety, Guardrails & Trust

The Anthropic→operator→user trust hierarchy, prompt injection defense, human-in-the-loop, Constitutional AI & RLHF, honesty boundaries.

Structured Output & Data

JSON schema-constrained output, forced tool use for extraction, multimodal/vision inputs, output formatting reliability.

Performance & Cost

Prompt caching, Message Batches API, model selection (Haiku/Sonnet/Opus), latency optimization, token efficiency.

RAG & Retrieval

Chunking strategies, embeddings, semantic vs. keyword search, reranking, source attribution, grounding on private data.

Evaluation & Testing

Rubric-based evaluation, model-as-judge, why numerical self-confidence is unreliable, regression testing of prompts.

How should you prepare?

  1. Build something first. Nothing cements the concepts like shipping a small project — an agent with a tool, a RAG bot, or an MCP server. The exam rewards practical intuition.
  2. Read the official docs above for each domain. Skim broadly first, then go deep on the areas you're least comfortable with.
  3. Work the learning path one level at a time. Apply each guide before moving on.
  4. Take timed practice tests in the Practice Test tab. Simulate real conditions: 60 questions, 90 minutes, no peeking.
  5. Use the focus breakdown. After each test, the results screen ranks your weakest domains. Study those, then retake — every test reshuffles for a fresh set.
  6. Active recall beats re-reading. For every question you miss, write one sentence explaining why the right answer is right and why your choice was wrong.
  7. Aim consistently above the pass line (70%) across several different randomized tests before booking the real exam.
