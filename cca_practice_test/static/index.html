What is this exam?

The Claude Certified Architect — Foundations (CCA-F) is a professional-level technical credential from Anthropic. It validates your ability to design, build, and deploy robust, production-grade applications using the Claude model family, the Claude Agent SDK, the Model Context Protocol (MCP), and Claude Code.

Unlike basic AI-literacy certifications, this exam is heavily scenario-based: it focuses on high-stakes architectural trade-offs, mitigating non-deterministic behavior, and working within real production-system limits. Most questions ask you to pick the best option among several technically viable ones.

Who should take it?

Solutions architects, software developers, and AI engineers with roughly 6+ months of hands-on experience building production systems with the Claude API. In practice that includes:

  • Solution architects & tech leads designing LLM-powered systems and making cost/latency/reliability/safety trade-offs.
  • Software engineers & developers shipping AI features and agents on the Anthropic API.
  • AI/ML practitioners moving from experimentation to production deployments with Claude.
  • Developer advocates, consultants, and founders who want a recognized credential demonstrating Claude expertise.

No formal prerequisites — but building at least one real project with the Claude API, the Agent SDK, or Claude Code makes the scenario questions far easier to reason about.

What will be asked? — The 5 exam domains & weightings

The exam is organized into five domains. The percentages are the official exam weightings — spend your study time in proportion to them. Domain 1 alone is over a quarter of the exam.

Domain 1 Agentic Architecture & Orchestration 27%

Agentic loops & terminating conditions (Agent SDK), coordinator-subagent (hub-and-spoke) orchestration, context isolation to prevent leakage, lifecycle hooks, task decomposition, and state tracking / session resumption after failures.

Domain 3 Claude Code Configuration & Workflows 20%

CLAUDE.md scoping hierarchy (user → project → directory), conditional rule loading via .claude/rules/ with YAML frontmatter, Plan Mode vs. Direct Execution, CI/CD integration, and custom slash commands in .claude/commands/.

Domain 4 Prompt Engineering & Structured Output 20%

Structured output via tool_use + JSON schema (preferred over asking for raw JSON), few-shot prompting, validation & retry loops for self-correction, batch vs. synchronous processing, and multi-instance "critic" verification.

Domain 2 Tool Design & MCP Integration 18%

MCP primitives — Tools (state-changing actions), Resources (read-only data), Prompts (reusable templates); tool boundaries (split vs. consolidate), "descriptions as code," and error propagation with structured error schemas and Human-in-the-Loop triggers.

Domain 5 Context Management & Reliability 15%

Context trimming & windowing, trimming vs. progressive summarization trade-offs, token economics with prompt caching, and provenance / confidence thresholds for autonomous decisions vs. routing to human review.

The practice test tags each question with finer-grained topics and shows a weakest-first breakdown on your results screen — use it to find which of these domains needs the most work.

The 6 core architectural scenarios

The exam drops you into the shoes of a lead architect. It randomly selects 4 of these 6 scenario environments — be ready for all six.

1 · Customer Support Resolution Agent

Resolve returns, disputes, and issues. Trade-off: autonomous execution vs. Human-in-the-Loop review, using confidence thresholds and a predictable escalation matrix.

2 · Code Generation with Claude Code

Scale Claude Code across a multi-developer team. Trade-off: resolving conflicting project constraints, e.g. a user-scope config overriding project-wide conventions via the CLAUDE.md hierarchy.

3 · Multi-Agent Research System

A coordinator-subagent framework that crawls documents and builds a dossier. Trade-off: preventing context leakage / token bloat by passing each subagent only the snippet it needs.

4 · Developer Productivity Assistants

A desktop assistant using built-in tools (Bash, File Editor) and custom MCP servers. Trade-off: security boundaries vs. autonomous capability; single-purpose tools with explicit JSON inputs.

5 · Claude Code for CI/CD Automation

Claude Code in GitHub Actions / GitLab pipelines for review, test generation, and PR verification. Trade-off: avoiding hung pipelines — run non-interactively (the -p flag, stdin redirects).

6 · Structured Data Extraction Pipelines

Parse millions of irregular PDFs / tax filings / logs into strict schemas. Trade-off: speed vs. validation integrity — a dual-pass, schema-enforced pipeline with retry loops that feed errors back.

How should you prepare?

  1. Build something first. Nothing cements the concepts like shipping a small project — an agent with a tool, a RAG bot, or an MCP server. The exam rewards practical intuition.
  2. Work the official Anthropic Academy roadmap in order (Claude 101 → Building with the Claude API → Claude Code in Action → Intro to MCP → MCP Advanced).
  3. Study in proportion to the domain weights. Domain 1 (Agentic Architecture, 27%) deserves the most time; don't over-invest in the 15% domain at its expense.
  4. Read the official docs above for each domain, going deepest on your weakest areas.
  5. Take timed practice tests in the Practice Test tab. Simulate real conditions: 60 questions, 120 minutes, no peeking.
  6. Use the focus breakdown. After each test, the results screen ranks your weakest topics. Study those, then retake — every test reshuffles for a fresh set.
  7. Active recall beats re-reading. For every question you miss, write one sentence explaining why the right answer is right and why your choice was wrong.
  8. Aim consistently above the pass line (≈ 72%, i.e. 720/1000) across several different randomized tests before booking the real exam.
